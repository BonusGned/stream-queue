# Правила

**[Фильм/Сериал/Аниме/AFK](https://github.com/BonusGned/stream-queue/blob/main/afk-queue.md)** контент 1ч - 200Р (пишите в какой озвучке), каждый час +200р.
Если оценка ниже 6.5 на всеми известных ресурсах ([IMDB](https://imdb.com)/[Kinopoisk](https://kinopoisk.ru)), ценник растет x2 и больше на мое усмотрение.

*Сериал, аниме и т.д заказывать полным сезоном!!! (Бывают исключения)*

**[Игры](https://github.com/BonusGned/stream-queue/blob/main/game-queue.md)** - 200Р умножить на часы игры по **[HowLongBeat](https://howlongbeat.com)**
Т.е игра допустим проходится за 4 часа, значит заказ - 800Р.

**Если игра откровенный каллллл - ценник выше (по договоренности)**

**!!!Игры должны быть легкодоступны или в наличии у стримера, также вы можете ее подарить.**
Заказы на мультиплееры по договоренности.

**[Список](https://backloggd.com)** игр которые точно можно заказать

Легкодоступные - игры со старых консолей, которые можно запустить через эмулятор.

**Также заказы можно делать с помощью накопленных баллов канала**

Также присутствует $$$ VIP очередь $$$ - туда вы можете по x2 цене отправлять заказы. Сама очередь является приоритетной.

Если что-то непонятно - лучше заранее обсудить со стримером, до заказа.
